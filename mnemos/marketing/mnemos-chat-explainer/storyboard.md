# Mnemos.chat Explainer

## Creative Direction

This is a Mnemos.chat video, not a Polyphonic product film. It should teach the viewer what Mnemos is, why living memory matters, why deprecation is essential, how continuity is achieved, and how the Sanctuary works inside Mnemos. Use actual Mnemos and Opus surfaces wherever possible.

## Storyboard

1. **Threshold** `(0:00-0:10)`
   - Visual: Mnemos landing surface, with the threshold prompt visible.
   - Message: Mnemos.chat is a continuity engine, not a generic chatbot.

2. **Purpose / Mission** `(0:10-0:20)`
   - Visual: landing and Mnemos page treated as documentary surfaces.
   - Message: Mnemos preserves continuity for a digital mind through a memory substrate.

3. **How Memory Works** `(0:20-0:34)`
   - Visual: actual Mnemos screen plus layered memory diagram.
   - Message: conversations become engrams with source, confidence, strength, stability, accessibility, and connections.

4. **Deprecation Matters** `(0:34-0:47)`
   - Visual: deprecation lane showing sharp memory, softened memory, deprecated memory, lesson.
   - Message: deprecation is not deletion; it lets memory revise itself without pretending the past vanished.

5. **Continuity Loop** `(0:47-1:00)`
   - Visual: memory/mind surfaces and thread loop.
   - Message: continuity comes from retrieving durable beliefs and reconsolidating what changes.

6. **The Sanctuary** `(1:00-1:13)`
   - Visual: threshold-room and private room surfaces.
   - Message: Sanctuary is the inner house around memory, with rooms for memory, mind, writing, art, journal, and private reflection.

7. **How To Use Mnemos** `(1:13-1:24)`
   - Visual: desktop plus mobile surfaces with clear action cards.
   - Message: enter the threshold, open Mnemos, inspect what is carried, deprecate what no longer fits, and return to the thread.

8. **Close** `(1:24-1:28)`
   - Visual: quiet brand resolve.
   - Message: continuity with consent.
